# Prediction Machines — интерактивная презентация

Автор: Сержан Біржан (APE2601)

Интерактивная презентация на казахском языке. Весь проект находится в одном файле `index.html`, сборка не нужна.

## Как открыть

Откройте `index.html` в браузере. Нужен интернет: скрипты и шрифты (Tailwind, three.js, Lucide, Google Fonts) подгружаются с CDN.

## Как выложить сайтом (GitHub Pages)

1. Откройте репозиторий на GitHub, затем Settings, затем Pages.
2. В Source выберите ветку `main` и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://ВАШ_НИК.github.io/НАЗВАНИЕ_РЕПО/`.
