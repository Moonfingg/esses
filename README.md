# Prediction Machines — интерактивті презентация

Автор: **Сержан Біржан**. Бір файлды сайт: `index.html` (сервер, сборка және `npm` керек емес).

## GitHub Pages-ке шығару
1. Жаңа репозиторий жасаңыз және `index.html` пен `README.md` файлдарын жүктеңіз.
2. **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Branch: `main`, папка: `/ (root)` → **Save**.
4. Бір минуттан кейін сайт `https://<username>.github.io/<repo>/` мекенжайында ашылады.
